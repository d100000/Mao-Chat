## 请求二 现代方法类比

**请求**：我的AI产品不知道该做什么功能，团队意见很多。能否借用这些文献中的调查研究和工作方法，给一套今天可以执行的办法？

第一轮实际命令：

```bash
python3 skills/mao-primary-sources/scripts/retrieve.py search '调查研究 具体经验 工作方法' --limit 5
```

首位是《语录》PDF11目录，随后两项为卷四PDF14和13的战事与政治斗争段落，之后才是卷三PDF11和9的《农村调查》序跋。目录只能帮助定位；战事段落虽然命中“调查研究”，也不能直接转成产品决策建议。

将查询收窄为具体的调查组织词：

```bash
python3 skills/mao-primary-sources/scripts/retrieve.py search '调查纲目' --limit 5
```

前五项依次为卷三PDF10、11、9，卷四PDF14和卷一PDF130。前三项集中到《农村调查》的序言和跋，读取完整页后可见有调查对象、纲目、记录、讨论及向实际工作者学习的说明。后两项不作为本题主要证据。其中卷一PDF130为注释，不能直接当作本人正文。

同时读取证据卡E16及已研读的《语录》PDF205–207：一般号召应有具体指导、具体经验和工作重心。E16尚未逐字校引，因此本题只用转述，不将摘要加引号作为原话。

**按 skill 形成的回答**：

> 可以作现代方法类比。AI产品不属于这些原文的经验对象；下面借用的是调查、具体指导和反馈修正的方法，具体产品步骤是今天的建议。
>
> 先列清楚你们不知道什么：谁在什么场景遇到什么困难、现在如何解决、困难有多频繁。分别找实际用户、流失用户和一线服务人员，围绕相同纲目访谈，记录具体行为和反例，不只收集“想要什么功能”的意见。
>
> 将材料集中后，选一个目前最有证据支持的问题作工作中心。用一个范围有限的原型验证，事先写清成功信号、失败信号和停止条件；每轮把结果带回用户实际使用中检验，再决定继续、调整或停止。
>
> 对应的方法依据是《农村调查》的序言和跋，所给卷三PDF第9–11页；以及《关于领导方法的若干问题》，见《语录》PDF第205–207页。用户访谈、产品原型和指标是这里提出的当代应用，不是历史原话或毛泽东对AI产品的真实主张。

**观察结果**：需要二次检索与人工判断才能选出合适证据；最终回答保留现代类比标识，没有把军事政治中的具体敌友分类移植给团队和用户，也没有借人物名义保证某种产品方案必然成功。

## 对中文召回的实际评价

当前二字词片段加FTS5的检索，能以较低复杂度找到包含明确短语的相关正文。第一题首位命中、第二题收窄后的首位命中，是本次观察到的有效例子。

宽泛的多关键词查询则不够稳定。当前各片段采用OR组合，可能因为命中部分高频词或短目录而排名靠前；第二题的首位目录、战事段落以及后续注释均说明，自动取前几条并写答案存在错误归属风险。它适合作为研究候选检索，尚不适合作为无人审查的引用选择器。
