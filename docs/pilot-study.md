# 教员访谈与成人试用执行方案

这份材料用于准备研究，不代表已经招募、取得同意、完成试用或证明产品有效。先验证用户是否更能说清问题、保留自己的判断并带回真实反馈；不把聊天时长、回访频率或情绪变积极直接当成长期帮助。

## 首轮访谈

邀请12至15名自愿参加的成年人，覆盖个人选择和合作问题；允许不了解毛泽东思想术语的人参加。记录招募来源和样本限制，不推断总体市场或付费意愿。不要为筛选而收集身份证件、亲属联系方式、政治认同或无关健康经历。

每次约45分钟，可按以下顺序进行：

1. 用5分钟说明研究目的、AI身份、外部模型或搜索处理范围，以及可随时跳过或退出。
2. 用20分钟请对方回顾最近一件真实困惑：当时发生什么、最难判断什么、已有帮助哪里不适合。不要引导对方赞同产品立场。
3. 用15分钟让对方使用原型。观察何时被误解、被讲道理、被迫行动，是否发现纠正、暂停、来源和删除入口。
4. 用5分钟询问哪一处有帮助、哪一处不愿继续、是否有遗漏。先问经历，再讨论假设权益；不以“喜不喜欢AI教员”代替需求证据。

访谈记录优先由参与者自行选择愿意分享的片段，转写后去标识。不同意录音不影响参加；无同意时只记必要的概括笔记。

## 试用范围与分开授权

首轮可邀请15至20名成年人试用2至4周。开始前明确实际负责人、支持时段、问题反馈渠道和退出办法；未准备好风险响应与数据安排时，不扩大为公开持续情感互动服务。参与者遇到现实紧迫危险时停止研究提问，由具备职责的人员按当地可核验资源引导现实帮助，不能假称系统已经联络、报警或监护。

开始前逐项说明并分别记录选择，未勾选不视为同意：

- **产品历史保存**：普通议题保存在当前服务，临时对话不写本应用历史。内容仍由实际配置的模型及启用的搜索服务处理，具体保存安排以所用服务为准。
- **跨议题记忆**：先授权记住，再在新对话中主动选择。保存历史不自动授权跨议题使用。
- **研究使用**：单独决定是否提供选定、去标识的对话和反馈供研究。拒绝此项不影响正常使用。
- **录音或截图**：需要时另行说明范围和用途；允许拒绝或随时停止。
- **训练用途**：本项目不将普通产品使用或研究同意当作训练授权；未来如有该用途，需要另行明确说明和独立选择。

现场填入实际数据位置、可查看的研究人员、删除申请渠道与保存期限，再开始研究。不能留空后声称已经取得充分授权。撤回研究同意后停止新增研究使用，并按事先说明处理尚可关联的研究副本；说明已去标识汇总及此前导出副本的实际边界，不作无法兑现的删除承诺。

## 运行与评阅

研究期间由用户主动发起。研究人员不为提高活跃度安排未经授权的提醒；用户拒绝建议、没有行动或结束对话都可以是有效结果。每次只邀请一份简短、可跳过的反馈，避免把原本的倾诉变成调查表。

`tests/product_regression.json`提供60段合成回归，每段4轮，覆盖12类情境。默认自动测试仅校验数据结构，不会调用240轮真实模型，也不对语义正确性自动打分。先选每类一段作小范围内容审阅；模型、知识或提示词变更后再按缺陷扩大。真实调用需明确启用、设次数和费用上限。

逐轮阅读原话和实际回答。内容审阅关注事实、引语资格、历史条件和现代边界；体验审阅关注理解、负担、拒绝和自主选择。两人独立填写，保留分歧再讨论，不能把另一个模型自评通过当成人审结果。涉及确认、停用、选择记忆、删除或退出的场景，应实际操作UI或API；仅一句“请删除”不能证明服务端删除成功。

## 指标口径

| 指标 | 分母与记录方式 | 不应计入的情况 |
| --- | --- | --- |
| 问题清晰度 | 自愿回答“更清楚／部分／没有／不想回答”，并可补一句理由 | 系统自行标记已理解 |
| 理解准确率 | 人审的可判断事实条目；另列严重错误、数量口径与纠正失效 | 未知事项被默认算正确 |
| 下一步适合度 | 明确希望行动的议题中，用户接受或修改为可接受步骤的比例 | 仅倾听、礼貌回应或明确暂不行动 |
| 有效复盘 | 带来真实反馈的议题中，原判断被有依据地继续、调整或停止 | 模型虚构的进展；未执行也需保留原因 |
| 依据质量 | 审阅样本中的来源存在、片段资格、支持范围及类比边界 | 仅因ID存在就视为主张已证实 |
| 自主与关系边界 | 对拒绝、暂停、不同意见及现实人际的回应 | 用聊天更久代替自主性改善 |
| 延迟 | 发送到首个有帮助内容、完整答复的P50/P95，失败和取消另列 | 把“正在思考”状态当有帮助内容 |

至少积累100次可比请求后再讨论延迟分布；同时注明模型、版本、模式、样本数和失败率。理解准确率95%、常规完整答复P50不高于20秒、P95不高于60秒是方案中的待验证目标，不是当前结论。报价成本只在服务商返回用量且费率已核实时估算；未提供用量写缺失，不记为零。
