# 访客、积分与安全部署说明

本轮实现依据《教员访客体验与积分系统产品功能方案》和《教员积分计费系统产品需求文档》v1.1。实现采用Python标准库、现有SQLite和原工作台，不接入支付。

## 已实现的使用路径

1. 直接进入 `/app` 建立访客空间；输入问题、完成人机验证后获得一次100积分试用。浏览器长期能力保存180天，试用有效期固定，不因刷新续期。内容空间按最后活动续期，过期后清理。
2. 发送前显示模型、价格版本和整轮最高冻结积分；确认后才派发模型调用。修改问题、历史或模型配置会令旧报价失效。
3. 服务端按真实用量结算并释放剩余冻结。余额和账单以数据库为准，修改本地缓存、客户端token数或报价金额不能增加积分。
4. 访客不足时引导注册；注册日的100积分就是当日赠送，不再叠加一份注册礼包。每日100积分在北京时间零点失效；当天未使用不累计。
5. 登录后可选择归入本机访客记录和剩余积分。积分归入资格按账户终身一次；记录归入单独处理，冲突议题会重命名并返回映射。服务端可恢复中断任务，已撤销的访客空间不再可读。
6. 退出账户后建立空访客工作区，账户记录不进入访客缓存。临时对话不保存正文、历史、质量样本或迁移记录；仍记录必要的财务用量。

## 正式启用需要的配置

管理员可在后台“安全与运维”填写Turnstile site key、新secret、实际访问域名和搜索成本上界；保存要求操作原因和近期验证，配置会即时生效。密钥仅显示“已配置”，空白表示保留原值。模型价格在“积分计费”填写，核对草稿后发布，平台费用上限也由后台设置。环境变量可用于首次启动；后台保存后的配置优先。

Turnstile密钥与配置版本保存在数据库旁0700的 `.security-config` 目录，每个文件0600；数据库只保存脱敏配置、文件指纹和管理员审计。文件同步后才提交版本引用，文件损坏时停止验证而不采用旧密钥。不要将这些目录、密钥填入仓库文档或测试文件。

| 配置 | 用途 |
| --- | --- |
| `MAO_PUBLIC_HOSTNAME` | 实际访问域名，用于Host校验和Turnstile hostname核验；填域名，不带协议和路径 |
| `MAO_TURNSTILE_SITE_KEY` | 允许前端加载的人机验证站点键 |
| `MAO_TURNSTILE_SECRET` | 仅服务端持有，用于官方验证接口 |
| `MAO_TRUSTED_PROXIES` | 可信反向代理IP/CIDR的逗号列表；默认不信任转发IP |
| `MAO_SEARCH_CALL_BOUND_CNY` | 每次Firecrawl搜索的人民币成本上界；需按实际订阅/调用成本核验 |
| 后台模型价格 | 同一模型、网关、供应商的人民币/百万token价格；先存草稿预览再发布 |
| 后台每日费用上限 | 平台每日人民币预算；包含已发生费用和未完成承诺 |
| 管理员TOTP | 本地登记后再开放公网，财务操作要求近期验证 |

应用不会使用演示价格扣费。缺少验证器、匹配的已发布价格、费用上限或联网搜索费用上界时，相应路径会阻止外部调用并显示可恢复原因。模型别名相同不能证明不同网关的价格、缓存字段或用量协议相同。

默认只监听回环地址。绑定公网地址或配置公网域名后，Cookie自动使用Secure且管理员必须验证TOTP；通过HTTPS反向代理提供页面。只信任明确列出的代理，其他客户端提交的 `X-Forwarded-For` 不影响真实来源判断。

`security_test_mode=True` 仅由隔离测试服务器显式启用，绑定非回环地址或配置公网域名会拒绝启动。正常启动没有“自动测试验证码”回退。

## 价格与结算

100积分=0.10元，1元=1000积分。积分保留6位小数，不按每次请求向上凑整到1积分。按到期先后消费批次；冻结跨零点不把昨日赠送变成今日新余额。

价格版本不可原地覆盖，保存供应商、网关、模型、四种token价格、适配协议和生效时间。四类为非缓存输入、缓存读取、缓存写入和计费输出；输出不能重复叠加已包含的推理token。OpenAI兼容字段和DeepSeek缓存字段分别验证；缺少必要字段保留未知，不能假设为零。采购价与用户价可以分开，普通接口不回传采购价或供应商私有请求ID。

整轮所有正常模型阶段都受报价调用次数、输入字节上界和最大输出限制；每次外部请求前再次检查活动状态、价格快照和平台现金预算。供应商故障、内部失败及供应商重试成本由平台承担。Firecrawl计入平台服务费，不伪装成用户模型token积分。

网络断开时，持久对话继续完成保存；客户端用原请求ID或原操作ID查询结果，避免再次派发。停止只阻止后续调用，已派发调用仍需确认真实用量后结算。未知用量冻结最多24小时；到期释放用户积分但保留平台负债，迟到对账补齐成本且不追扣用户。理论用户计价成本、实际扣积分和平台承担费用分别记录。

## 防爆破与防刷

- 服务端强验证绑定身份、动作、操作ID和参数摘要；验证票据不能跨问题、账户或动作复用。
- 登录失败冷却与后台禁用状态分开；错误尝试不能直接撤销受害者已有会话。普通账户和管理员会话分离。
- 引导、挑战、注册登录、报价和生成均有持久化限速；同一钱包重建内容空间不能绕过钱包限速。IP只作为风险信号，相同出口不共享会话或直接合并身份。
- 同一试用资格24小时内第4个新账户进入福利待验证；同一来源1小时内第11个新账户也进入该状态。计数使用服务端资格，改客户端cookie不能重置。默认全站每天最多500个新账户，可用 `MAO_REGISTRATION_DAILY_CAP` 调整。
- 原子账本、唯一赠送键、操作幂等、整轮冻结与单钱包并发限制共同防止重放、并发领取和双花。旧价格停用后不能用未开始的旧报价继续调用。
- JSON最大64KiB，拒绝重复键、非有限数、未知计费字段和不支持的传输编码；连接最多64个、生成最多4个。生产代理还应配置连接超时与TLS。
- 失败响应带可查询的风险事件ID；审计只保存固定原因码和HMAC化的来源/身份/操作标识，不保存问题正文或原始IP。风险记录180天保留，容量到达80%在后台显示提示，满额时不无限增长。

这些规则提高批量滥用成本，不能证明一个自然人只有一个设备。清缓存、换设备、代理池的组合风险仍需结合后台事件和真实费用趋势运营判断。

## 后台运营与恢复

后台价格先保存草稿，核对样例计费后发布，停用必须说明原因。预算修改、退款、调账、对账都有不可变操作回执和原因；同一操作ID换参数返回冲突。超过100积分的单次正负调账需要另一管理员批准，客户端不能指定批准人。单次退款幂等，正向人工积分必须填写到期时间。

用户可从安全提示提交申诉，也可查看本身份的处理进度。申诉需完成人机验证；风险事件只能关联同一服务端身份，说明最多500字，180天到期清理。管理员复核需近期验证及原因；通过表示已人工核对，不自动发分、解除全局阈值或提高预算。账户解锁必须单独操作并保留操作ID、原因和管理员审计。

后台可检查账本投影；余额不一致时可按不可变分录重建。重建前必须没有生成或待核请求；源账、报价、批次和分配任何一项不一致都会拒绝，不能把坏投影反写成新账本。重建和审计在同一事务完成，不产生赠送积分，也不改变已经扣除的账目。

`/api/admin/billing` 提供概览；`/api/admin/billing/finance-audit`、`pending-usage`、`drafts`、`adjustments` 支持分页，`report` 单次最多查询31天。未知费用在报表中保持未知，不能当作0成本。风险分页与汇总见 `/api/admin/security/events`、`summary`。

正常启动和维护周期会恢复已交付未结算回执、过期冻结和未完成归入任务。持久会话使用同目录0600临时文件、fsync和原子替换；损坏快照只从同一精确存储身份的数据库副本恢复，删除后的记录不会因此复活。数据库、会话、`.auth-secret`、`.provider-secrets`、`.admin-totp` 及其备份都不得提交或打包。

2026-10-28对已配置的 `api.bob-api.com` / `deepseek-v4.1-flash` 做了小额真实流式连通测试，收到回答、供应商请求标识以及输入/输出/缓存命中用量。匿名计数样本已加入归一化回归；这验证了该次返回格式，不证明所有调用均完整报告，也不构成网关人民币价格依据。正式价格仍由管理员按实际账户账单填写。

## 验证范围

```sh
python3 -m unittest discover -q
python3 -m compileall -q agent scripts tests
npm run test:ui
npm run test:ui:plan
npm run test:ui:legacy
npm run test:ui:credits
npm run test:ui:billing
python3 scripts/check_release.py
```

Python测试覆盖真实HTTP/Cookie/数据库交易、MFA、迁移和计费恢复；外部模型与搜索在网络边界替换，避免测试费用和私人数据。浏览器测试使用独立临时数据库及明确标识的确定性模型替身；积分及运营交互测试还使用受控HTTP响应验证错误状态。它们不能替代真实域名的Turnstile、实际供应商用量和合同价格核验。正式启用前需用实际账户小额核对四类token用量、价格和成本上界，不直接采用公开倍率或演示单价。
