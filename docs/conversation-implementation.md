## 核对结果

原系统已经具备 SSE、公开处境整理、本地方法和案例检索、引用回查、停止及原请求费用查询。原先正文在整轮复核结束后才发送；浏览器收到正文后重复替换整条消息。联网由页面开关控制，开启但缺少搜索费用配置时会阻断报价。

## P0：自动检索、实际进展、分段发布和就地说明

- 移除对话页联网开关。后台提供检索策略，模型按需要调用工具；倾听和澄清一般不搜索，历史与方法优先本地，近期事实按需查网页。历史模式继续禁用联网。
- 搜索密钥或费用上界缺失时退回本地对话，并明示外部事实未核实。可用性、费用上界与策略版本参与报价摘要；报价后变化需要重新确认。搜索调用仍受平台预算约束，不把 Firecrawl 成本冒充模型 token 消耗。
- 搜索只接受最多120字的主题词。请求发出及计费前拦截常见联系方式、标识符、完整倾诉式语句，以及从用户原话中明确识别的姓名。模型还受搜索最小化指令约束；规则不是覆盖所有个人信息的实体识别器。
- 助手消息内展示真实事件：整理理解、查本地资料、等待搜索候选、联系现实条件、复核回答。可以展开记录，完成或中止后结束当前状态。展示公开理解和执行进展，不透传模型内部推理。
- 保留原有私有初稿及最终复核调用。最终复核期间，每个完整语义段落通过来源、可识别直接引语、资料版本检查后立即发送。引用缺少本轮卡片时提前做精确本地回查；整轮合计最多回查6个ID，不增加固定模型调用。
- 严格篇幅要求、待核来源前缀、缺少原著依据、非流式供应商，以及研究/历史等没有该复核阶段的路径，继续整篇缓冲并明确记录输出方式。独立标题不算首段有效正文；跨段引号、未闭合代码块保持缓冲。补齐多行直接引语和超长引语的检查，防止利用分段绕过核验。
- 已发布前缀之后出现不合格引语或资格变化时，终止本轮并标为未完成，不用新答案静默覆盖已经看见的段落。段落核对不等于自动证明全部转述、历史因果或现代类比正确。
- 浏览器持续追加段落，完成时不重建已有正文节点。已收到的完整段落可以查看引用；不加人工打字延迟。向上阅读时停止跟随，提供“有新内容，回到底部”。主动停止保留已收正文并标为未完成；普通断线沿用原请求查询和恢复，不能自动再次生成或再次扣费。
- 知识词和出处提供鼠标悬停、键盘聚焦、点击固定，手机使用底部说明面板。说明取自本轮合格资料，展示方法概括、原始背景、回答中的现代应用片段、边界及出处。案例显示有限事实、资料缺口和缺少独立结果证据；不将其包装为已证实成功案例。不是另起模型生成未经核对的百科解释。
- 后台分别显示首次状态反馈与首段正文的 P50/P95，以及逐段复核/整篇缓冲的样本数量。没有把加载提示、标题或兼容分段呈现计作模型首段生成提速。

阶段验证：运行时测试验证首段可在供应商结束前发布、私有草稿不外泄、晚到的不合格引用不发布、资料版本变更中止、篇幅限制保留缓冲、提前精确回查、搜索隐私拦截及自动能力报价绑定。浏览器验证普通倾听、真实段落追加、节点保持、悬浮/聚焦/Escape、移动说明及滚动行为。

## P1：理解纠偏与继续讨论

- 在当前消息提供补充或纠正入口。生成中提交更正会停止旧请求，等待原请求与费用状态确认；未确认结束时保留编辑内容，阻止新一轮重叠生成。
- 新条件作为下一轮用户原话进入输入框，经原有报价确认再发送；必要时带上尚未保存的原问题。旧消息标明基于更正前条件。不会只改页面摘要而让旧请求继续生成。
- 完成后，未确认的理解可以进入已有逐条确认/纠正记录；用户确认过的记录不重复要求确认。
- 根据倾听、澄清或分析阶段展示少量后续入口，例如继续倾诉、补充关键情况、说明这一步为什么做不到、带结果复盘。入口只填写草稿，不自动发送、不创建已接受行动、不授权长期记忆。

阶段验证：浏览器完成“生成首段 → 提交更正 → 停止并确认费用 → 带入新条件 → 确认发送 → 新请求包含更正”的实际路径；验证跟进入口不自动发送或接受行动。既有明确更正优先于旧上下文、行动状态和费用幂等测试继续通过。

## 验收边界

- 仍需真实网关的对话配对评审与延迟/用量对账。当前测试使用隔离数据库和确定性供应商替身，不能据此承诺真实响应速度改善或内容分析质量。
- 原有整篇初稿仍需完成；首段改善发生在最终复核阶段。历史模式、严格表达约束及其他保守路径有意保留整篇检查。
- 主动停止的未完成正文在当前页面保留，不冒充完整轮次进入服务器对话历史；临时对话继续不持久化正文。普通网络断线会尽量完成原请求并从服务器恢复保存结果。
- 现有反馈继续统计有帮助/未帮助、事实/依据问题；模型费用仍以后台实际用量结算。“理解纠正率”“有效下一轮回复率”和“查看依据后的反馈率”尚无统一有效性口径，本次不以点击次数、续聊次数或回答长度伪称质量指标。
